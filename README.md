# 📝 Formulário de Múltipla Escolha

Este formulário foi criado para coletar respostas de múltipla escolha. Por favor, leia cada pergunta com atenção e selecione a alternativa que considerar correta.

👉 [Clique aqui para acessar o formulário](https://yayforms.link/EoGMP9V)

---

## 📌 Instruções

- Leia cada pergunta com atenção.
- Selecione **apenas uma alternativa** por questão.
- Após responder todas as perguntas, clique em **Enviar** no final do formulário.
- Você pode revisar suas respostas antes de enviar.
